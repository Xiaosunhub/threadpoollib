# 2026-10-07

## threadpool 库改造（include/threadpool.hpp + src/threadpool.cpp）

修复：
- worker 退出后 `std::thread` 对象残留在 `threads_` 里导致句柄泄漏。改为 `std::vector<std::unique_ptr<Worker>>` + `finished` 标志 + `reap_workers_locked()`，在 `create_worker_locked()` 里回收。
  实测（60 轮突发负载，12000 个任务）：旧版句柄数 153 → 503 → 923 持续增长；新版稳定在 97。
- `std::bind` 绑定参数改为 lambda + tuple（`std::decay_t` + `std::apply`），支持移动-only 参数与成员函数指针。
- worker 退出时不再持锁，避免与回收方（持锁 join）死锁。
- 析构函数先把 workers 换出再加锁范围外 join，避免锁住正在退出的 worker。
- `stop()` 时清除 paused 状态，否则 workers 会在 cv 上忙等。

新增：
- `RejectPolicy::CALLER_RUNS`
- `try_submit` / `try_submit_priority` / `try_submit_cancellable`（返回 `std::optional`，不抛异常）
- `wait()` / `wait_for()`（基于 `inflight_` 计数 + `cv_idle_`）
- `pause()` / `resume()` / `is_paused()`
- `clear()`
- `get_config()`、`Config::thread_init` 钩子、`TaskHandle::valid()`
- `PoolMetrics` 增加 `min_threads`/`max_threads`/`active`
- 删除拷贝/移动构造赋值

验证方式：无 g++/clang++，用 VS2022 的 cl.exe（`vcvars64.bat` 初始化环境，需写 .bat 脚本执行）编译，/W3 无警告；示例 + 压力测试（100 轮伸缩、4 生产者并发、IMMEDIATE 停止）全部通过。
